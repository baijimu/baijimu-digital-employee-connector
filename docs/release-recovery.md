# 发布工具与来源制品直传

2026-09-30，Connector 2.0.1 的三平台签名制品已生成。来源登记使用固定 CLI 0.73.1，经网关上传 ZIP 耗时 135.147 秒，超过用户断言 120 秒有效期；来源入站 30 秒时钟偏差允许接收，而后续权限调用严格拒绝过期身份。

用户确认制品应统一走已有直传流程。发布工具更新至已发布 CLI 0.92.0：来源服务授权 prepare，客户端直传对象存储，再以独立认证请求 register。来源服务继续拥有授权与不可变制品登记，不延长身份有效期、不扩大 PAT 权限。

恢复流程从应用不可变标签读取 connector.json 和制品身份，从经过验证的工作流主线提交读取恢复代码及其 release-tools.json。工具配置按脚本位置解析，不能按当前工作目录误用旧标签的 CLI 依赖。已公开的 2.0.1 使用原运行的签名字节，通过 recovery_run_id 恢复，不移动标签、不重建制品。
